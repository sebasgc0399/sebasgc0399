## Sobre mí

Desarrollador de software en C# / .NET, SQL Server y TypeScript. Trabajo de la interfaz a la base de datos en dos líneas de producto: aplicaciones web y punto de venta con Android nativo en Java.

Diseñé el estándar de manejo centralizado de errores que hoy usan 7 microservicios y el monolito de la plataforma. Antes pasé 3 años poniendo en producción facturación y nómina electrónica para más de 175 clientes.

## Herramientas para programar con IA

Además de programar con IA, construyo las herramientas con las que trabajo.

**[odd-workspace-template](https://github.com/sebasgc0399/odd-workspace-template)**: plugin de Claude Code que convierte las reglas de un proyecto en chequeos. Los hooks revisan cada edición contra las reglas de su capa, los cambios grandes los escriben agentes con compuerta y cada revisión deja un recibo atado al diff.
